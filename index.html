Hardware & Cloud Architecture

  • Controller: ESP32-D0WD-V3 Dual-Core Wi-Fi SoC
  • Pulse & Oximetry: MAX30102 Optical Sensor (Heart Rate & SpO2)
  • Cardiac Monitoring: AD8232 Single-Lead ECG Front-End
  • Thermal Probe: DS18B20 / LM35 Body Temperature Sensor
  • Local Display & Cloud: 0.96″ I2C OLED + ThingSpeak REST API
